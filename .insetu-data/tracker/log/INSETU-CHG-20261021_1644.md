## Description
* **Kernel Bootloader & App Factory Protocol (`akasa/__init__.py`)**: Formalized the top-level application initialization lifecycle into `configure()` (Phase A: headless process tuning, namespace and suffix registration) and `init_app()` (Phase B: Flask transport wiring, token authentication gate, request-context SQLite connection cleanup, HTTP anti-caching headers, and SSE streaming). Added `boot()` with Werkzeug reloader detection and `reset_state()` for test harness isolation.
* **Process Resource Governance & WSGI Security (`akasa/__init__.py`)**: Implemented `tune_process_resources()` to raise `RLIMIT_NOFILE` to 65,536, bound `MALLOC_ARENA_MAX=2`, and set thread stack sizes to 1 MB. Added `ForceHTTPSProxyFix` middleware to enforce HTTPS routing behind reverse proxies and trusted tunnel suffixes.
* **Synchronous Pending-Write Overlay (`akasa.vfs`)**: Introduced `_VFS_PENDING_WRITES` memory overlay with monotonic sequencing (`_stage_pending_write`, `_clear_pending_write`, `has_pending_vfs_write`). Enforced instant Read-Your-Writes consistency across `VFSTransaction.read()` and short-circuited idempotency evaluation prior to disk queue flushes.
* **Causal OCC & 3-Way Merge Engine (`akasa.vfs`)**: Implemented `_ANCESTOR_CACHE` ring buffer (up to 12 revisions per file, 1 MB max size), `compute_vfs_sha256()`, `record_vfs_ancestor()`, and `lookup_vfs_ancestor()`. Added `three_way_merge_text()` with a deterministic Zombie-ACK sub-sequence detector (`_is_subsequence_edit`) and pure-Python hunk merger for concurrent file edits. Appended SHA-256 `base_hash` to all `vfs_mutated` save event receipts.
* **Self-Healing SQLite Recovery (`akasa.db`)**: Added `recover_corrupt_databases()` to salvage rows from quarantined `*.db.corrupt_*` database dumps via SQLite `ATTACH DATABASE` before auto-quarantine dumps are purged. Added `migrate_legacy_sqlite_paths()` and just-in-time schema validation for dynamically opened connections in `get_connection()`.
* **Universal Binary Execution Subsystem (`akasa.process`)**: Added `execute_binary()` resolving executable binaries across system `PATH`, virtual environment directories (`sys.executable`), and fallback Python CLI modules (`python -m <module>`). Wrapped all execution in `ProcessManager.run()` and `popen()`.
* **Event Bus Query Dispatchers & DI Passthrough (`akasa.hooks`)**: Introduced `emit_first()`, `emit_merge_dict()`, and `emit_merge_list()` on `HookRegistry`. Replaced hardcoded SSE forwarding with dynamic `register_sse_passthrough()`. Added unwrapped extension identity tracking (`_akasa_ext_name`) to prevent duplicate listener registrations across module reload boundaries.
* **Substrate Purity & Domain Decoupling (`akasa.extension`, `akasa.auth`)**: Stripped application-specific manifest methods (`manifest`, `get_manifest_files`, `save_manifest`) from `ExtensionContext`. Replaced hardcoded hostname checks (`.ts.net`) with `register_trusted_host_suffix()` in `akasa.utils` and `is_trusted_origin` hook delegation. Scoped daemon settings in `SettingsManager` to `<control_dir>/host.json` to isolate routing physics in `<control_dir>/system.json`.
* **Extension SDK Sugar & Context Injection (`akasa.extension`)**: Added `@ext_bp.on()` decorator on `AkasaExtension` to automatically inject hydrated `ExtensionContext` when the handler's first parameter is `ctx`. Added `get_db()`, `get_active_modules()`, and `emit_sse()` to `ExtensionContext`.
* **Worker Re-Entrancy Guard (`akasa.workers`)**: Guarded `run_parallel()` against deadlock when nested inside executing `Akasa-IO` threads by falling back to sequential execution.
