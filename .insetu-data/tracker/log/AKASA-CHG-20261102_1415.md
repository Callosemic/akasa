## Description
* **Recursive Dynamic Settings Schema Materialization (`akasa.extension`)**:
  * Implemented `_materialize_schema_node()` in `akasa.extension` to recursively evaluate declarative settings schema specifications for tenant workspaces.
  * Added dynamic evaluation of callable schema specifications, resolving tenant `workspace_id` parameters via `inspect.signature` inspection.
  * Added recursive evaluation for nested schema structures, including callable or collection specifications in `item_schema`, `fields`, and `columns`.
  * Added dynamic resolution for callable field-level `options` and `default` generators, gracefully falling back to empty lists or `None` upon evaluation exceptions.
  * Updated `get_registered_settings_schemas()` to pass raw schemas through `_materialize_schema_node()`, guaranteeing that downstream API consumers receive fully materialized dictionaries.
  * Updated extension route `GET settings/schema` to materialize dynamic schema nodes before returning HTTP JSON responses, preventing JSON serialization errors on un-evaluated callables.
* **Architectural Cartography & Repository Documentation Alignment**:
  * Updated `CODE_INDEX.md` to reflect project repository root files (`.gitignore`, `LICENSE`, `NOTICE`) and cleansed stray staging annotations on `get_registered_settings_schemas`.
  * Updated `README.md` with refined architectural highlights, PyPI and Python version badges, concise security model guidelines, and streamlined quick-start instructions.
  * Synchronized `akasa/docs/02_kernel_api_and_ioc_contracts.md` to formally document recursive settings schema materialization and dynamic schema reflection contracts.
