## Description
* **Kernel Memory Governance (`reclaim_process_memory`)**: Added process memory trimming in `akasa.utils` utilizing explicit Python garbage collection (`gc.collect()`) and glibc arena release (`malloc_trim(0)`). Integrated memory reclamation into DAG completion, sequential chain completion, and ephemeral artifact sweeps.
* **Bounded Parallel I/O Subsystem**: Implemented `run_parallel` in `akasa.workers` using a bounded 4-worker thread pool (`Akasa-IO`), enforcing deterministic thread-local connection eviction (`close_thread_connections`) in worker thread cleanup blocks. Exposed parallel mapping to extensions via `ctx.jobs.map_parallel()`.
* **Bounded Asynchronous Event Bus**: Replaced unmanaged daemon thread spawns in `HookRegistry.emit_background` with a bounded 4-worker `ThreadPoolExecutor` (`Akasa-EventBus`), maintaining fallback thread dispatching during interpreter shutdown.
* **Master Encryption Key Rotation**: Implemented `rotate_master_key` in `akasa.auth` to re-encrypt secrets across all tenant workspaces (`secrets.json`) and update `master_key.txt` with `0o600` file permissions. Migrated security updates from synchronous endpoint routing to the `@hooks.on('security_settings_updated')` event listener.
* **Secret Masking Sentinel Protocol**: Introduced `MASKED_SECRET_SENTINEL` (`••••••••`) in `akasa.extension`. Updated `SettingsManager.get` and `get_all` with `mask_secrets=True` support, and updated `set` and `update` to drop sentinel values to prevent accidental credential overwrites.
* **Strict Canonical URI Enforcement**: Enforced explicit RFC 3986 URI validation (`://`) across `VFSTransaction.save`, `delete`, and `read`, rejecting bare relative paths with `ValueError` unless explicitly marked as `is_absolute_artifact`.
* **Memory Footprint & Cache Optimization**:
  * Reduced SQLite connection `PRAGMA cache_size` from `-8000` (8 MB) to `-2000` (2 MB) per connection.
  * Replaced `copy.deepcopy` inside `@thread_safe_cache` with shallow dict/list copies to eliminate high-frequency cache overhead.
  * Reduced `_VFS_READ_CACHE` capacity from 32 MB to 8 MB, lowering the single-file cache threshold from 2 MB to 1 MB.
  * Reduced Metronome worker pool capacity from 20 to 8 threads (`Akasa-Worker`).
* **Selection Expansion Normalization**: Refactored `ExtensionContext.expand_selection` to guarantee strict `List[str]` returns, recursive directory traversal via `vfs.walk`, and exclusion of `.gitkeep` / `.keep` markers.
* **Metronome Shutdown Resilience**: Added `_shutdown_event` checks and `RuntimeError` handling in `_metronome_loop` to reset running tasks back to `pending` upon executor shutdown.
