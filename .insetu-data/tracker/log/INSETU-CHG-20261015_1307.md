## Description
* **VFS Bulk Mutation Execution**: Introduced `execute_vfs_bulk` in `akasa.vfs` to queue multi-file operations (`save`, `move`, `delete`) as a unified payload onto the asynchronous VFS write pipeline.
* **Worker Bulk Action Processing**: Added `action == "bulk"` branch to `_vfs_commit_worker`, executing disk mutations sequentially, batching SQLite ledger insertions via `executemany`, and dispatching a single consolidated `vfs_mutated` event.
* **VFSTransaction Batch Aggregation**: Updated `VFSTransaction.__exit__` to automatically aggregate buffered multi-file mutations into `execute_vfs_bulk`, reserving single `execute_vfs_save` calls strictly for isolated 1-item operations.
