## Description
* Stripped domain-specific logic from core kernel modules (`auth`, `sync`, `utils`, `vfs`) and delegated decisions to host applications via IoC hook signals (`execute_identity_handshake`, `evaluate_blocking_task`, `request_vfs_ignore_dirs`).
* Created `akasa/process.py` introducing `ProcessManager` for sandboxed subprocess execution within mounted volume boundaries (`ctx.exec`).
* Standardized `get_workspace_physics()` to return a uniform 2-tuple `(config_path, workspace_root)` across the substrate.
* Routed configuration writes and ephemeral artifact cleanup through non-blocking async VFS pipeline methods (`execute_vfs_save`, `execute_vfs_delete`).
* Isolated extension database paths to `ext/<ext_name>/db/<ext_name>.db` and expanded `AkasaURI` path manipulation utilities.
