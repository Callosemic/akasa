## Description
* **Selection Expansion Filtering (`akasa/extension.py`):** Enhanced `ExtensionContext.expand_selection()` with an optional `gather_only=False` keyword parameter. Forwards `gather_only` to the `expand_selection` hook event, allowing host applications and Tier 2 context engines to gather selection items without executing expensive file reads or dynamic expansion logic.
* **VFS Unmounted Volume Guardrails (`akasa/vfs.py`):** Implemented pre-flight volume mounting validation in `execute_vfs_save()` and `VFSTransaction.save()`. Transactions targeting unmounted volume URIs are dropped cleanly with a warning log rather than queueing invalid background commits. Added path resolution verification in `execute_vfs_save_physical()` to prevent invalid disk operations.
* **Metronome Missing Callback Auto-Suspension (`akasa/workers/__init__.py`):** Added fault-tolerance recovery in `_execute_job()` when a scheduled job references an unregistered callback. The Metronome logs a warning and sets `interval_ms = 0`, forcing immediate suspension and removal of the job from the `jobs` ledger to eliminate infinite execution loops.
