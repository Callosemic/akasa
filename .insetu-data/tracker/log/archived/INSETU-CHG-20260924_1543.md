## Description
* **Thread-Local DB Connection Eviction on Corruption (`akasa/workers/__init__.py`):** Enhanced error recovery in `_metronome_loop()` to catch "malformed" or "corrupt" SQLite exceptions, automatically closing and purging stale database handles from thread-local storage (`_local.connections`). This allows the auto-healing database sub-system to re-initialize clean database pools on subsequent loop iterations without worker thread lockups or continuous failure loops.
