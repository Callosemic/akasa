## Description
* **Generic DAG Orchestration (`akasa/workers/__init__.py`):** Added `resolve_dag_chain()` to perform priority sorting and cycle-safe topological sorting of step definitions registered via hooks, automatically anchoring source, body, and sink components.
* **Pipeline State Reduction & Artifact Normalization (`akasa/workers/__init__.py`):** Enhanced `_execute_immediate_job` with automatic merging of `state_deltas` into `chain_state`, safe serialization of non-standard objects in `next_args_json`, and envelope normalization matching the `ChainStepArtifact` contract.
* **OpenAPI 3.0 Schema Reflection (`akasa/utils.py`, `akasa/extension.py`):** Added `typeddict_to_openapi()` utility for inspecting Python `TypedDict` annotations and emitting compliant OpenAPI JSON schemas. Wired `request_schema`, `response_schema`, and `docstring` parameters into `AkasaExtension.route()` and `bp.route_schemas`.
* **Centralized Exception Dispatch (`akasa/hooks.py`, `akasa/vfs.py`, `akasa/workers/__init__.py`):** Integrated background `system_error` hook emission across hook invocation failures, background worker crashes, and VFS commit worker write errors.
* **Boot Concurrency & Lock Resilience (`akasa/workers/__init__.py`):** Protected worker schema initialization with thread lock `_SCHEMA_INIT_LOCK` and added retry loops for database lock contention during multi-tenant boot sequences.
* **Substrate Terminology Purity (`akasa/sync.py`):** Renamed `is_compiling` telemetry flag to `is_pipeline_active`, evaluating agnostic DAG chains (`_chain`, `chain_history`, `is_pipeline`) rather than domain-specific compiler terms.
* **URI Protocol Enhancement (`akasa/uri.py`):** Expanded `AkasaURI` with class-preserving `.parent` and `.join()` methods, string representation methods (`__str__`, `__repr__`), equality comparison (`__eq__`), hashing (`__hash__`), and OS path protocol support (`__fspath__`).
* **Environment-Gated Debug Telemetry (`akasa/vfs.py`):** Suppressed verbose VFS console telemetry behind the `INSETU_DEBUG=1` environment check.
* **Lock-Free Cache Optimization (`akasa/utils.py`):** Streamlined fast-path read logic in `@thread_safe_cache` to minimize lock contention during cache hits.
