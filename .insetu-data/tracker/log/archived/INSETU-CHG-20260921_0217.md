## Description
* **SQLite Auto-Healing (`akasa/db.py`):** Added automated corruption detection (`PRAGMA quick_check(1)`) and database healing, isolating corrupt SQLite databases to `.corrupt_<timestamp>` backups, re-initializing clean connection pools, and re-applying declarative schemas.
* **Thread-Safe Single-Flight TTL Cache (`akasa/utils.py`):** Replaced direct mutable dictionary cache objects with a `@thread_safe_cache` decorator featuring single-flight execution barriers and invalidation race protection. Decoupled `load_config` invalidation via `config_mutated` event hooks.
* **Global SSE Event Publisher (`akasa/events.py`):** Introduced a thread-safe `EventBus` singleton (`sse_bus`) supporting queue-backed client subscriptions and non-blocking Server-Sent Event (`emit_sse`) broadcasting.
* **Queue-Based VFS Barrier Sentinels (`akasa/extension.py`):** Replaced sleep-loop polling in `SettingsManager._sync_vfs_barrier()` and `ExtensionContext.sync_vfs_barrier()` with queue-based barrier event sentinels (`{"action": "barrier", "barrier_event": event}`) for zero-CPU wait times.
* **Dependency-Injected Event Routing & SSE Auto-Forwarding (`akasa/hooks.py`):** Added `register_trusted_namespace()`, `register_extension_namespace()`, and `set_workspace_router()` interfaces to `HookRegistry`. Automated UI signal forwarding (`topology_resolved`) to the SSE bus.
* **UI Blocking Task Telemetry & Categorization (`akasa/sync.py`, `akasa/workers/__init__.py`):** Introduced `job_category` (`'ui_blocking'`, `'system_background'`) to `immediate_jobs`. Streamlined `get_system_deltas()` to filter active UI compilation tasks and broadcast live job progress via SSE.
* **VFS Event Stream Folding (`akasa/utils.py`):** Added `fold_vfs_events()` mathematical state machine for VFS event stream coalescence, hierarchical child path pruning, and creation/deletion annihilation.
* **Process Sandboxing Refinement (`akasa/process.py`):** Enhanced `ProcessManager` directory resolution to handle absolute and existing filesystem paths cleanly when resolving volume working directories.
