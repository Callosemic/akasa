## Description
* **Ring 4 Peer Classification & Origin Security (`akasa.auth.peer`, `akasa.auth`)**:
  * Implemented `akasa/auth/peer.py` establishing `classify_peer()` and frozen `PeerInfo` as the single source of truth for request origin evaluation without Flask coupling.
  * Codified fail-closed proxy detection: presence of any forwarding header (`Forwarded`, `X-Forwarded-*`, `X-Real-IP`, or host-registered proxy headers) disqualifies direct loopback trust.
  * Implemented rightmost-hop IP resolution: only the rightmost entry of `X-Forwarded-For` from a local proxy is trusted as the client address.
  * Added DNS-rebinding protection via `is_host_allowed()`, validating the Host header against loopbacks, registered exact hosts, and trusted suffixes.
  * Added `is_loopback_origin()` for `Origin` and `Referer` validation, defending against localhost drive-by CSRF attacks.
  * Updated `/auth/bootstrap` in `akasa.auth` to use `classify_peer()`, passing the classified `peer` object and sanitized `client_ip` to `execute_identity_handshake`.
* **DNS-Rebinding Gate & Bootloader Configuration (`akasa.__init__`)**:
  * Added `enforce_host_validation` parameter to `init_app()`, returning `421 Misdirected Request` on disallowed Host headers prior to route execution or token checks.
  * Extended `configure()` to accept `proxy_headers` and `allowed_hosts`.
  * Updated `reset_state()` to quiesce background workers first and invoke `_akasa_peer.reset()`.
* **Topological DAG Wavefronts & Template Primitives (`akasa.context`, `akasa.utils`)**:
  * Implemented `resolve_dag_wavefronts()` in Ring 0 using stdlib `graphlib.TopologicalSorter` for cycle-safe level-order wavefront compilation.
  * Added stdlib template parsing and substitution primitives: `extract_template_variables()` and `interpolate_template_variables()`.
  * Re-exported all new primitives through `akasa.utils`.
* **Worker Resilience & Sandbox Quiescing (`akasa.workers`, `akasa.vfs`)**:
  * Delegated DAG topological sorting in `resolve_dag_chain()` to `resolve_dag_wavefronts()`.
  * Added re-entrant `Akasa-IO` worker detection in `run_parallel()` via thread-local `_io_pool_local.in_pool` to avoid deadlock.
  * Added `_quiesce_background_workers()`, joining the Metronome thread and shutting down worker pools with `cancel_futures=True` during `reset()`.
  * Hardened `vfs.reset()` to drain queued writes with `sync_vfs_barrier()` before purging caches.
* **Settings Introspection & MCP Capabilities (`akasa.extension`)**:
  * Added `SettingsManager.is_set()` to distinguish explicit configurations from schema defaults across scopes.
  * Added `ExtensionContext.get_registered_capabilities()`.
  * Added `mcp_expose` flag support to `AkasaExtension.route()`.
* **AST Fitness Rule & Behavioral Test Coverage**:
  * Codified `FORWARDED_HEADER_MEMBRANE` in `KernelFitnessVisitor`, prohibiting direct forwarding header inspection outside `akasa/auth/peer.py`.
  * Added unit test suites: `test_auth_peer_trust.py`, `test_settings_is_set.py`, `test_vfs_reset_drain.py`, and `test_workers_reset_quiesce.py`.
  * Added CI stack battery workflow, Apache 2.0 `LICENSE`, and `NOTICE`.
