## Description
* **Verbatim Shell Pipeline Execution (`akasa.process`)**:
  * Enhanced `execute_binary()` to evaluate `kwargs.get("shell")`, passing shell commands through unmolested as unified strings via `shlex.join()` when provided as sequences.
  * Bypassed binary path and Python module fallback resolution when `shell=True`, preventing compound shell expressions (such as `a && b`) from being erroneously resolved to `python -m "a && b"`.
  * Enforced non-empty validation on shell command inputs with explicit `ValueError`.
* **Process-Tree Session Group Isolation & Lifecycle Settlement (`akasa.process`)**:
  * Factored out `_spawn()` to isolate boot token stripping (`AKASA_BOOT_TOKEN`) across standard `subprocess.run()`, streaming `subprocess.Popen()`, and timed executions.
  * Implemented `_run_with_tree_timeout()` ensuring timed child processes lead an isolated session (`start_new_session=True` on POSIX) or distinct process group (`CREATE_NEW_PROCESS_GROUP` on Windows).
  * Implemented `_kill_process_tree()` to terminate entire process hierarchies via `os.killpg(proc.pid, signal.SIGKILL)` on POSIX or `taskkill /F /T /PID <pid>` on Windows upon timeout or base exceptions.
  * Added bounded 5-second pipe-drain grace periods (`proc.communicate(timeout=5)`) and descendant leak suppression during timeout cleanup, preventing hung I/O descriptors from locking caller threads.
