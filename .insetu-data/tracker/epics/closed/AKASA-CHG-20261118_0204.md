## Description
* **Public-Origin Read-Only VFS Boundary (`akasa/__init__.py`, `akasa/vfs.py`):** Configured `init_app()` to bind unauthenticated requests matching `public_routes`, `public_prefixes`, or `public_suffixes` (excluding `/auth/bootstrap`) to an `ExecutionFrame` with `origin="public"` across the request lifecycle, and enforced `403` read-only rejections across `execute_vfs_save`, `execute_vfs_delete`, `execute_vfs_move`, and `execute_vfs_bulk` when `get_current_origin() == "public"`.
* **Ring 0 `BoundedCache` & Causal Config Caching (`akasa/context.py`, `akasa/state.py`, `akasa/utils.py`):** Added `BoundedCache` and `get_registered_cache_stats()` with causal `revision` token validation, monotonic TTL expiry, defensive container cloning (including `tuple` support in `clone_json_value()`), telemetry reporting, and automatic `reset_state()` purging; migrated `akasa/state.py` to `_JSON_CONFIG_CACHE`.
* **`ExecutionFrame.baggage` & `contextvars` Propagation (`akasa/context.py`, `akasa/workers/__init__.py`, `akasa/utils.py`):** Added `baggage` and `get_current_baggage()` to `ExecutionFrame` with nested frame merging, propagated `contextvars` (`contextvars.copy_context().run`) into `Akasa-IO` threads in `run_parallel()`, and carried `_origin` and `_baggage` through worker job payloads (`_prepare_job_payload`, `_execute_immediate_job`, `_execute_job`).
* **In-Memory VFS Contract & Causal Revision Reads (`akasa/vfs.py`):** Added `VFSTransaction.read_with_revision()` and `MemoryVFSTransaction` implementing the full `VFSTransaction` contract in RAM without disk I/O.
* **Unified Schema Migration on Connection Open (`akasa/db.py`):** Extracted `_apply_schema_to_conn()` so both `apply_declarative_schema()` and `get_connection()` execute full `CREATE TABLE`, `ALTER TABLE ADD COLUMN` diffing, and `CREATE INDEX` migrations, tracking applied connection IDs in `_local.applied_schemas` with deterministic cleanup on connection eviction.
* **Documentation & Governance (`docs/adrs/0015_*.md`, `docs/00_index.md`, `docs/01_engineering_standards.md`, `docs/02_kernel_api_and_ioc_contracts.md`, `CODE_INDEX.md`):** Published ADR 0015 and synchronized architecture standards, API contracts, and `CODE_INDEX.md`.

## Notes / Execution Log
* Added behavioral unit tests in `tests/unit/test_bounded_cache_baggage_and_public_origin.py` covering `BoundedCache` LRU/TTL/revision/reset behavior, `ExecutionFrame.baggage` propagation across nested frames, `run_parallel()`, and worker jobs, `origin="public"` read-only VFS enforcement, `MemoryVFSTransaction` / `read_with_revision()`, and `db.py` connection eviction schema re-application.
