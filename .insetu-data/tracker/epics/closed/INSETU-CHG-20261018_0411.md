## Description
* **Parallel DAG Workflow Orchestration**: Implemented `start_dag_chain`, `resolve_dag_chain`, and runtime coordinator logic in `akasa.workers` to support parallel task execution with topological sorting, anchor ordering, and automatic pipeline state reduction (`_merge_state_deltas`).
* **In-Memory VFS Read LRU Caching**: Added thread-safe 32 MB write-through RAM cache (`_VFS_READ_CACHE`) in `akasa.vfs` with single-stat idempotency checks (`_is_file_identical`), eliminating redundant disk I/O and suppressing duplicate mutation events.
* **Inter-Workspace Volume Router (`ws://`)**: Introduced `InterWorkspaceVFSDriver` to resolve cross-tenant data paths (`ws://<workspace_id>/<domain>/<path>`) with dependency-injected policy authorization (`set_mount_authorizer`) and strict read-only enforcement.
* **Two-Tier Thread-Local Connection Pooling**: Refactored `akasa.db` connection storage to `workspace_id -> db_name` with two-tier LRU limits (3 workspaces, 4 DBs per workspace). Relocated database files to `<control_dir>/cache/db/` and added `close_thread_connections()` to prevent file descriptor leaks in WSGI/worker threads.
* **Dynamic Metronome Loop Synchronization**: Replaced 1.0s sleep polling with `threading.Condition` (`_metronome_wakeup`), waking worker threads on demand when jobs are scheduled or state changes occur.
* **In-Memory Job Wait Sentinel**: Added `_active_job_events` tracking and `wait_for_jobs()` / `ctx.jobs.wait_for()` to allow non-blocking synchronization on immediate tasks.
* **Fast Active Pipeline Evaluation**: Introduced `get_active_pipeline_modules()` in `akasa.sync` for single-query pipeline state resolution across active DAG coordinators and chained background jobs.
* **Spatial Physics Hardening**: Added `is_subpath()` in `akasa.utils` for boundary resolution, replacing string prefix comparisons in sandbox and artifact path resolvers. Upgraded config file caching to nanosecond timestamps (`st_mtime_ns`).
* **SDK Context & Store Expansion**: Added ephemeral artifact management, status polling, and execution logs to `JobManager`. Scoped `StoreManager` to `<control_dir>/data/<ext_name>/` with automated legacy path migration. Added cross-tenant mount utilities (`get_shared_mounts`, `iter_shared_mount_files`) to `ExtensionContext`.
* **Synchronous First-Boot Master Key Generation**: Updated `get_master_key()` in `akasa.auth` to persist keys synchronously with `0o600` permissions to avoid startup race conditions with the async VFS pipeline.

## Notes / Execution Log
