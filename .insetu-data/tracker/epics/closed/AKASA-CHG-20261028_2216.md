## Description
* **Single Source of Truth Peer Classification (`akasa.auth.peer`)**:
  * Implemented `classify_peer(remote_addr, headers)` returning an immutable slotted `PeerInfo` record.
  * Enforced fail-closed proxy detection: any forwarding header (`Forwarded`, `X-Forwarded-*`, `X-Real-IP`, or host-registered proxy headers) marks the request as proxied (`via_proxy=True`) and disqualifies localhost trust (`is_direct_loopback=False`).
  * Enforced rightmost-hop parsing for `X-Forwarded-For` from loopback proxies to prevent leftmost client IP spoofing.
  * Added `register_proxy_header()` and `register_allowed_host()` dependency injection interfaces.
* **DNS-Rebinding Host Header Validation Gate (`akasa.init_app`)**:
  * Added pre-routing Host header validation rejecting requests with foreign Host headers via `421 Misdirected Request`.
  * Accepts loopback IP/hostnames, registered trusted tunnel suffixes (`register_trusted_host_suffix`), and exact allowed hosts (`register_allowed_host`).
* **Forwarded Header Membrane AST Fitness Mandate (`tests/fitness/rules_python.py`)**:
  * Codified `FORWARDED_HEADER_MEMBRANE` in `KernelFitnessVisitor`, flagging any direct reads of client forwarding headers outside `akasa/auth/peer.py`.
* **Explicit Setting State Tracking (`SettingsManager.is_set`)**:
  * Added `.is_set(key, repo=None)` to `SettingsManager`, accurately differentiating persisted values from schema defaults across daemon, workspace, repo, and secure scopes.
* **Test Sandbox Quiescence & VFS Drainage (`akasa.reset_state`)**:
  * Verified that `reset_state()` synchronously drains and barriers all pending asynchronous VFS write queues prior to daemon CWD changes (`tests/unit/test_vfs_reset_drain.py`).
  * Confirmed that `reset_state()` stops Metronome dispatcher threads and executor thread pools to prevent cross-sandbox thread leakage (`tests/unit/test_workers_reset_quiesce.py`).
* **Packaging, CI & Documentation**:
  * Added Apache-2.0 `LICENSE` and `NOTICE`.
  * Added upstream stack CI battery trigger `.github/workflows/ci.yml`.
  * Updated `README.md` with complete architecture guide, quick start, security model, and testing instructions.
  * Updated `pyproject.toml` with author metadata, URLs, and classifiers.
