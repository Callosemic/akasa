## Description
* **Host-Protected VFS Target Enforcement (`akasa.vfs`)**:
  * Implemented `register_protected_vfs_targets(*targets)` allowing host applications to inject `(namespace, basename)` tuples or normalized paths that VFS mutations must never modify.
  * Implemented `_protected_segment_match()` to enforce whole-segment boundary evaluation and block paths that shadow protected modules at Python import time, including package directories (`<stem>/__init__.py`), shared library extensions (`<stem>.cpython-*.so`), compiled bytecode (`<stem>.pyc`), and `__pycache__` entries.
  * Wired `_is_s8_protected_target()` checks into `execute_vfs_save()`, `execute_vfs_delete()`, `execute_vfs_move()`, and `execute_vfs_bulk()`, returning generic error payloads (`_PROTECTED_WRITE_MESSAGE`) that reveal no host-specific filenames.
* **Bootloader Wiring (`akasa.__init__`)**:
  * Added `protected_vfs_targets` parameter to `akasa.configure()`, routing tuples and string path specifications directly to `register_protected_vfs_targets()`.
  * Wired `_akasa_vfs.drain_write_queue()` into `reset_state()` immediately before `_akasa_context.reset()`, guaranteeing pending asynchronous writes commit while the originating sandbox's tenant resolver and mount table are fully intact.
* **VFS Write Queue Drainage Primitives (`akasa.vfs`)**:
  * Factored out `drain_write_queue(timeout=5.0)` to block until all queued VFS writes reach physical storage, handling barriers and catching timeouts during harness resets.
  * Updated `vfs.reset()` to delegate to `drain_write_queue()` before clearing the in-memory read cache, pending-write overlay, and ancestor ring buffer.
* **Reserved Template Namespace Expansion (`akasa.context`)**:
  * Added `"sys"` to `_RESERVED_TEMPLATE_MACROS` and `"sys."` to `_RESERVED_TEMPLATE_PREFIXES` in Ring 0 `extract_template_variables()`.
  * Extended `interpolate_template_variables()` to treat `"sys."` prefixes as reserved runtime orchestrator namespaces, preventing fallback pipe segments from resolving literal defaults for internal system tags.
