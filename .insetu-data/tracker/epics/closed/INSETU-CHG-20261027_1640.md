## Description
* **5-Ring Strict Acyclic Dependency Architecture**: Partitioned the micro-kernel into concentric rings (Ring 0 `context`/`uri`/`types` -> Ring 1 `events`/`hooks` -> Ring 2 `db`/`vfs`/`state`/`utils` -> Ring 3 `process`/`workers`/`sync` -> Ring 4 `auth`/`extension`/`__init__`). Enforced zero upward imports and eliminated inline function imports across all modules.
* **ExecutionFrame & ContextVars Tenant Tracking (`akasa.context`)**: Introduced a slotted `ExecutionFrame` on a `contextvars.ContextVar` via `execution_frame()`, providing transport-agnostic tenant, method, payload, and job ID tracking across CLI, HTTP, IPC, and worker executions without Flask request coupling.
* **Headless Tenant Resolution (`akasa.context`, `akasa.__init__`)**: Added `set_tenant_resolver()` and `resolve_active_tenant()` allowing host applications to inject custom tenant resolution callables. Wired Flask HTTP request header resolution as an optional Ring 4 transport adapter.
* **Inter-Process File Locking (`akasa.context`)**: Implemented `_file_write_lock` supporting POSIX `fcntl.flock` and Windows `msvcrt.locking` on `.state.lock`, integrated into `atomic_write_bytes` and `atomic_write_text` to serialize control-plane configuration updates across daemon processes.
* **Causal Parsed-Object JSON Cache (`akasa.state`)**: Added `_JSON_PARSED_CACHE` in `akasa.state`, caching parsed JSON data structures keyed by VFS causal revision tokens (`-pending_seq` or `st_mtime_ns`) to eliminate redundant `json.loads()` deserialization and deepcopy overhead.
* **Unified Read-Your-Writes Primitive (`akasa.vfs`)**: Implemented `read_cached_physical_text()`, inspecting `_VFS_PENDING_WRITES` (returning `(-seq, content)`), `_VFS_READ_CACHE`, and physical disk with a single stat call. Updated `VFSTransaction.read()` to delegate directly to this primitive.
* **Acyclic Dependency Injection Interfaces**: Added `hooks.set_hook_authorizer()` and `hooks.set_thread_cleanup()` in `akasa.hooks`, `set_db_physics_resolvers()` in `akasa.db`, and `set_vfs_artifact_path_resolver()` in `akasa.vfs` to eliminate upward imports between Ring 1/2 modules.
* **Subsystem `reset()` Isolation Contracts**: Added standardized `reset()` contracts to `context`, `db`, `vfs`, `state`, and `workers`, orchestrated centrally via `akasa.reset_state()` for test harness isolation.
* **Ephemeral Scratch Buffer SDK (`akasa.extension`)**: Added `ctx.jobs.write_scratch(filename, content, ttl_seconds)` to atomically write temporary files to `<control_dir>/cache/<ext>/scratch/` and automatically register them in the TTL garbage collection ledger.
* **AST Fitness Hardening (`tests/fitness/`)**: Codified `KERNEL_RING_DAG_MANDATE`, `KERNEL_TRANSPORT_ISOLATION`, `STRICT_TOP_LEVEL_IMPORTS_MANDATE`, `UNITTEST_DISCOVERY_MANDATE`, and `DUPLICATE_TOP_LEVEL_DEFINITION` rules into `KernelFitnessVisitor`.
