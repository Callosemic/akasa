## Description
* Implemented `_build_table_ddl_and_indexes` in `akasa.db` to parse declarative table constraints (`__constraints__`) and automated index definitions (`__indexes__`) while separating functional column definitions.
* Extended `apply_declarative_schema` and lazy connection initialization in `get_connection` to create composite constraints and execute idempotent `CREATE INDEX IF NOT EXISTS` statements during schema migration.
* Bounded metadata keys starting with `__` to ensure column diffing during `ALTER TABLE ADD COLUMN` operations does not attempt to apply metadata as physical table columns.
* Expanded the thread-local SQLite connection pool capacity from 4 to 16 active database connections per workspace before triggering LRU handle eviction, preventing connection cycling in high-extension workloads.
* Reconciled stale markers in `vfs://akasa/CODE_INDEX.md` and updated engineering standards and contract documentation in `docs/01_engineering_standards.md` and `docs/02_kernel_api_and_ioc_contracts.md`.
