## Description
* **Host Policy for Protected VFS Targets (`akasa.vfs`, `akasa`)**:
  * Implemented `set_protected_write_handler(handler)` dependency injection interface, allowing the host application to intercept VFS mutations (`save`, `delete`, `move`, `bulk`) targeting protected paths and return custom responses without writing to disk.
  * Retained fail-closed refusal (HTTP 403) when no handler is registered.
  * Implemented `_route_protected_mutation()` routing unconfirmed mutations to the host handler with contextual metadata (`action`, `workspace_id`, `filepath`, `dest_path`, `content`, `data`, `origin`).
  * Implemented `is_protected_vfs_target(filepath, workspace_id, is_absolute_artifact)` public query helper for proactive protected path resolution.
  * Implemented `execute_confirmed_protected_write(workspace_id, filepath, content, data)` using a context variable (`_CONFIRMED_PROTECTED_WRITE`) to bypass the protected target check for a single call while preserving volume mount validation and the write queue.
  * Updated `execute_vfs_bulk()` to route protected operations to the host handler and return their responses under a dedicated `protected` payload key.
  * Updated `VFSTransaction` context manager to evaluate protected mutations immediately rather than buffering them, returning the host handler's response directly to the caller.
* **Execution Origin Tracking (`akasa.context`, `akasa.utils`)**:
  * Extended `ExecutionFrame` with an `origin` slot to capture the initiating caller identity across transports (`HTTP` -> `"ui"`, `WORKER` -> `"worker"`, `CLI` -> `"cli"`, `IPC` -> `"internal"`), with support for explicit host-defined origins (e.g., `"mcp"`, `"routine"`, `"agent"`).
  * Added `DEFAULT_ORIGIN_BY_TRANSPORT` mapping and `get_current_origin()` helper.
  * Ensured nested execution frames inherit the caller's origin, giving explicit origin arguments precedence over transport defaults.
  * Re-exported `get_current_origin` through `akasa.utils`.
* **Asynchronous Origin Propagation across Hooks and Workers (`akasa.hooks`, `akasa.workers`)**:
  * Updated `HookRegistry.emit_background()` to capture `get_current_origin()` at emission time and bind it to the asynchronous background worker frame.
  * Updated `_prepare_job_payload()` in `akasa.workers` to serialize the submitter's origin under `_origin` in the job argument dictionary.
  * Updated `_execute_immediate_job()` and `_execute_job()` to unpack `_origin` and bind it to the executing worker's `ExecutionFrame`.
* **Testing & Cartography Parity (`tests/unit`, `CODE_INDEX.md`)**:
  * Added `tests/unit/test_protected_write_handler.py` verifying refusal without handlers, host interception, bulk routing, confirmed write single-use bypasses, transaction bypass mechanics, public query fidelity, and execution origin inheritance and worker persistence.
  * Updated `CODE_INDEX.md` and indexed `ADR 0014: Host Policy for Protected Writes and Execution Origin`.
