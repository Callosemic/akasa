## Description
* **Isolated Stdlib Credential Store (`akasa.auth.credentials`)**:
  * Implemented a self-contained, pure standard-library credential store operating under `<control_dir>/auth/` (`0o700` directory, `0o600` file permissions) with zero dependencies on `Flask`, `cryptography`, or internal `akasa` modules.
  * Architected to support direct path loading (`importlib.util.spec_from_file_location`) by host recovery and lifeboat servers when the primary `akasa` package root cannot be imported.
  * Implemented race-safe session token creation using `os.open(..., O_CREAT | O_EXCL)`, atomic temporary file writes with `os.fsync`, and constant-time token verification (`hmac.compare_digest`).
  * Added POSIX permission auditing via `permission_problems()` and automatic tightening of loose file permissions.
* **Lazy Zero-Side-Effect Boot Token Initialization (`akasa.auth`, `akasa`)**:
  * Replaced eager module-import session token generation with `get_boot_token()`, guaranteeing that importing `akasa` or `akasa.auth` creates no files or directories on disk.
  * Synchronized token resolution across threads with `_BOOT_TOKEN_LOCK`, prioritizing explicit `AKASA_BOOT_TOKEN` environment variables, falling back to durable disk storage, and degrading to per-process memory tokens if the control directory is read-only.
  * Added module-level `__getattr__(name)` hooks in `akasa` and `akasa.auth` to preserve backward compatibility for legacy `BOOT_TOKEN` references.
  * Wired `_akasa_credentials.verify_token(client_token, get_boot_token())` into `init_app` request gate validation.
* **Claim-Guarded Worker Execution Settlement (`akasa.workers`)**:
  * Hardened post-execution settlement in `_execute_job()` to constrain rescheduling and one-shot deletion queries with `WHERE id=? AND status='running'`.
  * Guarantees that if a job re-submits itself during execution (such as debounced build pipelines) or transitions to `paused` via `pause_job()`, the concluding worker execution does not overwrite the new schedule or inadvertently delete the task record.
