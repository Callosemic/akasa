## Description
* **5-Ring DAG AST Fitness Enforcement (`tests/fitness/`)**:
  * Implemented `KERNEL_RING_MAP` and Ring DAG mandate (`KERNEL_RING_DAG_MANDATE`) in `KernelFitnessVisitor`, verifying that modules in Ring $N$ never import upward from Ring $M$ ($M > N$).
  * Enforced `KERNEL_TRANSPORT_ISOLATION` to ban importing `flask` or WSGI transports across Rings 0–3 (`types`, `uri`, `context`, `events`, `hooks`, `db`, `vfs`, `state`, `utils`, `process`, `workers`, `sync`).
  * Enforced `STRICT_TOP_LEVEL_IMPORTS_MANDATE` banning inline `import` and `from ... import` statements inside functions or methods in all kernel modules.
  * Added `state.py` and `context.py` to `VFS_WRITE_WHITELIST`.
  * Relaxed `CARTOGRAPHER_PLACEHOLDER_BAN` in `check_python_files()` to skip class and function definitions marked with `# [comment required]`, focusing strictly on unresolved file and directory path entries.
* **Architectural Cartography (`CODE_INDEX.md`)**:
  * Updated `CODE_INDEX.md` with comprehensive function, class, and method inventory across all 15 micro-kernel modules, documenting two-phase bootloader mechanics, slotted `ExecutionFrame`, atomic file writes, causal parsed-object JSON caching, and dual-pool workers.
* **Behavioral Unit Test Suite Hardening (`tests/unit/test_kernel_hardening.py`)**:
  * Added `test_json_config_pending_write_read_your_writes_and_locking` verifying immediate Read-Your-Writes consistency across `save_json_config` and `load_json_config`.
  * Added `test_injectable_tenant_resolver_decoupling` verifying `akasa.configure(tenant_resolver=...)` and `execution_frame()` handle tenant identification in headless environments without Flask coupling.
  * Added `test_ring2_parsed_json_cache_avoids_redundant_json_loads` verifying that `load_json_config` returns cached parsed JSON structures without redundant `json.loads` calls on cache hits.
  * Added `test_job_manager_write_scratch_registers_ephemeral_artifact` verifying atomic scratch buffer creation and TTL cleanup registration in `ctx.jobs.write_scratch`.
  * Added `test_fitness_rules_enforce_ring_dag_and_transport_isolation` asserting zero violations across the live codebase and validating synthetic AST checks against upward ring imports, transport leaks, and inline imports.
