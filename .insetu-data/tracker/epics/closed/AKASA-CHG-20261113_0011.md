## Description
* Extracted `three_way_merge_text` from `akasa/vfs.py` into a pure-stdlib Ring 0 module `akasa/merge.py` (re-exported by `akasa/vfs.py` for backward compatibility) designed for statement-level parity with `sutram/js/merge.js`.
* Replaced `difflib.SequenceMatcher` and `_is_subsequence_edit` with patience-anchor diffing (`_merge_unique_anchors`), bounded LCS fallback (`_merge_lcs_hunks`, `_MERGE_LCS_CELL_LIMIT = 250000`), late-acknowledgement detection (`_merge_contains_run`), and ordered hunk replay (`_merge_goes_first`) to prevent dropped deletions next to edited lines.
* Added `class Row(sqlite3.Row)` in `akasa/db.py` with `.get(key, default=None)` and configured `conn.row_factory = Row` across pooled connections in `get_connection()`.
* Updated `CODE_INDEX.md` to index `akasa/merge.py`, `akasa.db.Row`, `.github/workflows/ci.yml`, and `tests/unit/test_three_way_merge.py`.

## Notes / Execution Log
* Added behavioral and randomized property tests in `tests/unit/test_three_way_merge.py` verifying adjacent edits, deletion preservation, late-acknowledgement fast paths, Windows line endings, and 20,000-line merge scaling.
* Added `test_query_rows_support_get_and_still_behave_as_rows` in `tests/unit/test_kernel_hardening.py` verifying `.get()`, `NULL` preservation, tuple value unpacking, and joined column retention.
